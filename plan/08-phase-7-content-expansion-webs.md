# Phase 7 (Track 1) — Content expansion: Serengeti, Chesapeake Bay, Little Rock Lake

## Objective
Grow the atlas from its current webs to a credible multi-biome collection by adding three well-documented published food webs: **Serengeti** (grassland — the flagship terrestrial web), **Chesapeake Bay** (estuary — weighted flows), **Little Rock Lake** (freshwater lake). The existing pipeline, schema, and validator are reused unchanged; this phase is curation work plus small UI updates to surface the new content.

## Read first
`plan/00-MASTER-PROMPT.md` (product principles, salmon rule, design language) + this file. Data contract: `packages/schema` + `docs/data-format.md`.

## Source data (vetted — use these; flag immediately if inaccessible)

1. **Serengeti** — de Visser, Freymann & Olff (2011), "The Serengeti food web: empirical quantification and analysis of topological changes under increasing human impact", *Journal of Animal Ecology* 80: 484–494. The paper publishes the full node list and consumer–resource link matrix in its Supporting Information (Appendices S1–S4): 86 pristine trophic nodes + basal resources, links unweighted. Curate a **~25-node subset** following the paper's own trophic aggregation (it already aggregates to trophic species and functional plant types). Provenance: **empirical** (links from literature review documented in S2). Notes for curation: keep iconic species identifiable where the paper's nodes allow (lion, hyena, wildebeest, zebra); basal nodes are functional plant types (grasses/herbs, trees/shrubs, seeds, detritus) — this is correct, do not invent plant species. Edges are `qualitative: true` — no diet percentages exist in this dataset.
2. **Chesapeake Bay** — NOAA Technical Memorandum, "Fisheries Ecosystem Model of the Chesapeake Bay" (Ecopath-based, 45 functional groups with documented diet compositions per group in the appendix). Curate **20–25 groups**; where diet percentages are documented, encode as real `weight` values with the appendix section cited; otherwise qualitative. Provenance: **empirical**.
3. **Little Rock Lake (Wisconsin)** — Martinez (1991), "Artifacts or attributes? Effects of resolution on the Little Rock Lake food web", *Ecological Monographs* 61. 181 taxa / 92 trophic species; unweighted network publicly downloadable via network repositories (Netzschleuder/graph-tool collection: `foodweb_little_rock`). Aggregate to **~20 trophic groups**. Provenance: **empirical**. Bonus: Martinez's paper is itself about aggregation resolution — reference it in the web's "About this web" text as a real-world illustration of the salmon rule.

## Tasks

1. **Curate the three webs** through the standard pipeline: one JSON per web, `validate:data` green, aggregation statements on every non-species node, full citations, lat/lng for the map (Phase 8 depends on this), provenance badges.
2. **Per-web layout curation:** deterministic layout + hand-tuned layout hints; record overrides in the JSON.
3. **Update the browse layer:** activate the Grassland, Freshwater, and Estuary entries (add estuary to the biome enum if absent — schema change requires updating `packages/schema`, validator, and mockup-consistent card styling). Each new web card needs its one-line hook (e.g. Serengeti: "The most-studied savanna on Earth — and what extinction does to it").
4. **Serengeti special content:** the de Visser paper documents realistic extinction sequences under human impact. Add a note in this web's info panel: "This web was published with an analysis of species loss under human pressure — try removing large predators and compare." (Content only — no new features.)
5. **Index regeneration:** `data/webs/index.json` regenerated by the pipeline, not hand-edited.

## Constraints
- The salmon rule applies with extra force to Serengeti and Little Rock Lake: aggregation follows the source paper's own trophic-species scheme, nothing finer.
- If a source PDF/supplement proves inaccessible, STOP and flag it in the Checkpoint Report — do not reconstruct links from memory or secondary summaries.
- Qualitative edges must render with the existing dashed style; check the legend explains them on qualitative-heavy webs.

## Acceptance criteria
- [ ] 3 new webs pass `validate:data` (plus the deliberately-broken fixture still fails).
- [ ] Serengeti ≤ 25 nodes, all edges qualitative, basal nodes are functional plant types, citation complete.
- [ ] Chesapeake Bay: every weighted edge traceable to a documented diet composition; the rest qualitative.
- [ ] Little Rock Lake aggregation documented (181 taxa → ~20 groups) in the web's metadata + About text references Martinez 1991.
- [ ] Browse layer shows all webs across ≥ 3 newly activated biomes; "Coming soon" removed only where content actually shipped.
- [ ] All webs have accurate lat/lng in metadata.

## Checkpoint Report
Standard format + a table: web, biome, nodes, edges, % qualitative, primary source, curator judgment calls. Flag any source-access problems and any species-name disputes (common name vs. paper label).
