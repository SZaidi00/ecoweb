## Verified matrix locations (for Stage 3)

- **qassinnguit-glacier-foreland:** no machine-readable matrix exists. Source: [Gravesen et al. 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11652110/) **Figure 6** (gut-content web; link width = number of predators with prey DNA detected) + Tables **A6–A7** (SEM paths; coefficients are correlations, not diet fractions). Deposit [dryad.qfttdz0qt](https://doi.org/10.5061/dryad.qfttdz0qt) supplies only activity-density/environmental XLSX + README — use it for abundance context, not links. Three predators' guts were sequenced (*C. holmgreni*, *M. morio*, *N. rufescens* adult+larva); links for non-sequenced predators are literature/expert-supported and need explicit caveats (composite-leaning).
- **north-water-polynya:** appendix-only; on any marine-gate change, extract base-model **Table 2** (weighted diet matrix, 20 functional groups per Agent A) from *Arctic Science* 10:545–568 and keep Gillie et al. 2024 scenarios separate from the 2005–2007 baseline; EcoBase is the machine-readable route named by the PLOS paper.
- **northeast-greenland-shelf:** appendix-only; model files (StrathE2EPolar implementation, parameterisation code, simulated results) live in the three Strathclyde PURE deposits + `github.com/Jack-H-Laverick/MiMeMo.EastGreenlandShelf`; diets are Barents-calibrated — provenance decision required before any use.
- **greenland-deglaciation-ponds:** appendix-only; per-pond matrices at [dryad.n5tb2rc81](https://doi.org/10.5061/dryad.n5tb2rc81) — `data1.csv` (diet matrices) and `data2` (edge-list folder); check individual pond node counts before promotion.
- **young-sound-pelagic:** appendix-only; open chapter PDF (carbon-budget flow charts), below the 15-node minimum — parts-bin source, not a build candidate.
- **northeast-greenland-epibenthic:** rejected; isotope CSV only — do not derive links from isotope space.
