## Verified matrix location (for Stage 3)

- **magellanic-rabbit-steppe:** matrix obtained and parsed — GitHub [`IsidoraAvilaThieme/Magellanic_food_web`](https://github.com/IsidoraAvilaThieme/Magellanic_food_web), `Interaction list.xlsx`, sheets `Nodes` (207 rows; 206 linked) + `Links` (535 directed edges, **PredatorID → PreyID**). Companion files: `Network properties from Network 3D.xlsx` (network3D metrics export) and the rabbit-extinction R script (rabbit = node 30). **Salmon-rule / structure caveats Stage 3 must handle explicitly, not silently import:**
  1. **Basal-rule contamination:** the paper designates every species with predators but no recorded prey as "basal (primary producers) level" — the parsed 169 basal nodes include vertebrate herbivores (horse, beaver, upland goose, rodents, reptiles, insects). A naive import would place herbivores at the producer level and destroy the vertical layout. Herbivores must be re-leveled using the paper's Table 1 (Supplementary) diet categories and the Nativa origin labels.
  2. **Uneven resolution already bundled by the authors:** the >50%-diet rule collapses passerines / *Nothofagus* spp. etc. into cluster nodes — a source-documented aggregation precedent Stage 3 can cite in aggregation statements.
  3. Node-origin labels in the deposit (132 native / 27 exotic / 48 mixed) differ by ±3 from the paper text — cite the paper's version (132/29/45) for narrative, the deposit for edges.
  4. Column semantics: `Nativa` 0 = native, 1 = exotic, 2 = mixed (cattle/clover/beaver carry 1); `Conejo` 1 marks the rabbit only.
  5. Aggregating the 169-node basal pool to documented guilds is the main curation cost; the rabbit–plant–predator spine (rabbit 56 links; 12 predators incl. *Galictis cuja*; shared plants with guanaco/sheep/cattle) survives any defensible guilding, so the Stage 1 aggregation sketch (→ ~20–24 nodes) remains plausible — but the promotion decision belongs to Stage 3, not this file.
